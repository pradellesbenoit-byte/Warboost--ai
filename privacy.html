Confidentialité — bêta Safe Launch

Principe : le joueur choisit les données qu’il fournit à WarBoost.

La synchronisation cloud et l’analyse IA nécessitent une connexion WarBoost et un consentement bêta. Le consentement peut être retiré sur l’appareil.

Données traitées

  • E-mail de connexion et identifiant de compte WarBoost via le service d’authentification Supabase configuré.
  • Profil de jeu saisi, escouades, héros, Drone, Alliance, VS, Saison, boutique et historique de progression fournis ou confirmés par le joueur.
  • Données techniques minimales nécessaires au fonctionnement et aux diagnostics.

Captures WarBoost Scan

Une capture choisie par le joueur est redimensionnée dans le navigateur puis envoyée au service de vision/IA configuré afin d’en extraire les données visibles utiles. Le code WarBoost de cette version n’enregistre pas l’image brute dans le profil joueur après l’analyse. Les valeurs extraites et confirmées peuvent, elles, être enregistrées dans le profil WarBoost. Évite d’envoyer une image contenant des données personnelles sans rapport avec le jeu.

Service client et tickets

Lorsqu’un joueur crée volontairement un ticket, WarBoost enregistre le numéro du ticket, l’identifiant du compte, l’e-mail du compte, le pseudo s’il est disponible, la catégorie, le sujet, la description, le statut, les réponses et les diagnostics techniques choisis. Une capture de support est facultative ; elle est compressée côté appareil, limitée à 2 Mo et stockée dans un espace privé séparé du profil joueur. Les captures de support ne sont accessibles que par le joueur propriétaire du ticket et les comptes support autorisés, via un lien temporaire.

WarBoost ne demande ni ne stocke le mot de passe dans un ticket. Les informations de support sont utilisées pour traiter la demande, assurer le suivi et sécuriser le service.

Stockage et comptes

Des données peuvent être conservées localement sur l’appareil et, avec consentement, dans le cloud WarBoost/Supabase. Les mises à jour sont conçues pour préserver les données existantes. Le mot de passe est traité par le fournisseur d’authentification ; WarBoost ne l’enregistre pas en clair dans son profil joueur.

Retrait du consentement et demandes

Retirer le consentement bêta sur l’appareil bloque les nouveaux envois cloud/IA depuis cet appareil mais n’efface pas automatiquement les données déjà enregistrées. Pour une demande d’accès, d’export, de correction ou de suppression pendant la bêta, utilise le Service client WarBoost intégré à l’application.

Services externes

Selon la configuration du déploiement, Supabase peut être utilisé pour l’authentification, le stockage des données et les tickets de support, et un fournisseur de vision/IA peut traiter les captures ou demandes d’analyse. Cette version ne se connecte pas aux serveurs ou comptes Last War et n’effectue aucun scraping du jeu.

English summary

Player-consented WarBoost account/profile data may be stored locally and in the configured Supabase cloud. V2.5.24 support tickets may store the account identity, ticket content, replies, selected diagnostics and an optional compressed private screenshot. Passwords are never collected in support tickets. Support attachments are private and exposed only through short-lived authorized links.
