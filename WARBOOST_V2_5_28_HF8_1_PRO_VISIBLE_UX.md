# WarBoost V2.5.28 HF8.1 — PRO Visible UX

Correctif UX de HF8. La logique commerciale HF8 existait dans le tiroir Compte WarBoost, mais elle n'était pas exposée comme module principal. HF8.1 ajoute une carte **WarBoost PRO** directement sur l'accueil.

- Un toucher sur la carte PRO ouvre le Compte WarBoost et positionne directement l'écran sur la section WarBoost PRO.
- La bêta reste gratuite pour les testeurs invités.
- Le prix commercial prévu reste 4,99 € / mois.
- Aucun paiement n'est activé en bêta.
- Aucun accès externe Last War, scraping ou automatisation n'est activé.
- Les données Joueur, Scan, Drone, VS, Saison, Alliance, activité et historique sont conservées.
- Le contrôle R5/R4 Serveur + Alliance HF7 reste inchangé.
- Les 23 langues explicites + Auto sont conservées; la révision HF8.1 est propagée au libellé de version sans ajouter de texte non traduit.
