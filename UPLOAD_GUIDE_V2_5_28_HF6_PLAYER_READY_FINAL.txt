SMOKE TEST RÉEL OBLIGATOIRE
1. Ouvrir le lien stable Preview de public-beta-safe-launch.
2. En-tête : WarBoost V2.5.28 HF6.
3. Se connecter avec le compte test déjà utilisé ; profil, escouades, Drone, Alliance et historique doivent réapparaître sans rescan forcé.
4. Profil Last War : pseudo + serveur + alliance exacts.
5. Confirmer un événement réellement participé dans Joueur puis Synchroniser WarBoost.
6. Alliance R5/R4 : le joueur doit rester lié à sa ligne du roster ; aucun membre supplémentaire ne doit être créé.
7. Résumé Alliance : le compte lié et les preuves connues doivent se mettre à jour ; une absence de donnée doit rester non évaluée.
8. Suivi détaillé : pseudo Last War visible avec compteurs, date(s), événement(s), statut(s) et source(s). Aucune adresse e-mail dans la vue Alliance.
9. Tester un statut importé R5/R4 (sur un joueur test) : absent_confirmed / not_selected / excused ; ces statuts ne doivent pas devenir « inactif ».
10. Diagnostic PRO : TOP 3 personnalisé, données existantes conservées.
11. Boutique IA : alignée sur Diagnostic, aucune offre historique présentée comme actuelle.
12. VS : jour actuel correct, adversaire inconnu non inventé, Aujourd’hui / À garder / À éviter.
13. Saison : inter-saison historique, aucune S7 inventée.
14. Service client : créer/lire/répondre à un ticket test.
15. Mot de passe oublié : vérifier le lien stable Preview.
16. Invitations : tester un deuxième compte invité et vérifier qu’un compte révoqué reste bloqué.
