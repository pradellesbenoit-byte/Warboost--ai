# WarBoost V1.4.8 — Reliable Hero Save

- Confirmation des 5 héros enregistrée directement via `/api/state` avant de rafraîchir l’interface.
- Le bouton utilise une délégation d’événement stable pour les éléments recréés dynamiquement.
- En cas d’échec réseau/cloud, les 5 sélections restent visibles et peuvent être réessayées sans ressaisie.
- Après succès, l’escouade reste ouverte et affiche immédiatement les noms enregistrés.
- Messages d’enregistrement/erreur traduits dans toutes les langues WarBoost.
