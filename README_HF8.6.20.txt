INSTALLATION
1. Use GitHub branch public-beta-safe-launch.
2. Extract this ZIP.
3. Upload the CONTENTS of the extracted folder to the repository root, replacing existing files.
4. Do not delete any other file.
5. Wait for Vercel deployment.
6. Open WarBoost and confirm V2.5.28 HF8.6.20 is displayed.

EXPECTED LOGIN BEHAVIOUR
- Authentication may show “Connecté” immediately.
- While server access/profile verification is running, private squads and profile data remain hidden.
- After verification, the authenticated account profile appears.
- A first-time invited player with no cloud profile enters clean onboarding instead of seeing data from a previous account/device session.
