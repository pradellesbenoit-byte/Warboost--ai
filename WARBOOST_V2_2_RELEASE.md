# WarBoost V2.2 — Smart Diagnostic

Cette version consolide les corrections demandées avant présentation éditeur.

## Corrections principales
- `ROI` est remplacé dans l'interface par **Efficacité ressources**.
- Les cartes PRO affichent des niveaux lisibles (Impact / Efficacité) plutôt qu'une fausse précision numérique.
- Le Diagnostic PRO compare d'abord les **familles de goulots d'étranglement** : héros, étoiles, arme exclusive, équipement, Drone, données manquantes.
- Les 3 priorités évitent désormais d'être trois recommandations identiques si d'autres goulots sont proches.
- Une section **À ne pas améliorer / acheter maintenant** protège les ressources rares.
- Une escouade avec moins de 5 héros est marquée comme **composition partielle** et la confiance du diagnostic est plafonnée.
- La comparaison des escouades indique combien de héros ont réellement été détectés.
- La semaine VS utilise la semaine serveur courante au lieu de conserver une valeur locale obsolète.
- Le timing VS / Saison reste intégré dans l'arbitrage.
- Les visuels héros restent contextuels : escouades et recommandations, pas de galerie décorative.
- L'intégration officielle Last War reste explicitement en attente d'autorisation.

## Règle produit
WarBoost analyse et recommande. Il n'automatise aucune action dans Last War.
