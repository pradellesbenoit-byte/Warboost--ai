## Last War Event Calendar & Reset Times (Complete Schedule + Timezones)\#

> **Quick Answer**: Server reset occurs at 00:00 server time (UTC-2), which is 02:00 UTC. For Eastern Time, this is 9:00 PM (winter) or 10:00 PM (summer). All events, daily resets, and competition phases are based on this server time.

Last War: Survival runs on a complex event schedule that determines when you can earn the best rewards, compete with other alliances, and optimize your progression. Missing event windows means missing rewards you can never get back, which is why understanding the calendar system is critical for both competitive and casual players.

This guide breaks down every reset time, event schedule, and timezone conversion you need to plan your gameplay effectively.

## Understanding Server Time\#

Last War operates on a unified server time system that affects when events start, when daily resets occur, and when rewards are distributed. Before diving into specific schedules, you need to understand how server time works.

**Server time in Last War runs on UTC-2** (two hours behind Coordinated Universal Time). This means when the server clock shows midnight (00:00), it is actually 02:00 UTC. All event windows, daily resets, and competition phases are based on this server time.

### How to Check Server Time\#

You can check your server time by looking at any event timer in the game. The countdown displays how long until the next phase or reset, and you can work backwards to determine the current server time.

## Daily Reset Schedule\#

The daily reset is the foundation of your gameplay rhythm. At server reset, most game systems refresh and new opportunities become available.

### What Resets at 00:00 Server Time (02:00 UTC)\#

| System | What Happens |
| --- | --- |
| Daily Quests | Reset and become available for completion again |
| Alliance Help | Capacity refreshes for requesting and providing assistance |
| Arms Race | Matches you against 12-15 new opponents of similar base level |
| VIP Daily Chest | Becomes claimable |
| Free Shop Chests | Daily Sale and Weekly tabs reset |
| Radar Tasks | Task counters refresh |
| Alliance VS | Current day concludes, new day begins after 5-minute countdown |

## Timezone Conversions for Daily Reset\#

Converting server time to your local time is essential for planning. Here are the most common conversions for the daily reset at **00:00 server time (UTC-2)**:

| Timezone | Winter Time | Summer Time (DST) |
| --- | --- | --- |
| **Eastern Time (ET)** | 9:00 PM | 10:00 PM |
| **Pacific Time (PT)** | 6:00 PM | 7:00 PM |
| **Central European Time (CET)** | 3:00 AM | 4:00 AM |
| **UK Time (GMT/BST)** | 2:00 AM | 3:00 AM |
| **China Standard Time (CST)** | 10:00 AM | 10:00 AM |
| **Japan Standard Time (JST)** | 11:00 AM | 11:00 AM |
| **Australian Eastern Time (AEST)** | 12:00 PM (noon) | 12:00 PM (noon) |

The daily reset occurring at 9:00 PM Eastern means North American players can complete their daily activities in the evening, while European players need to either stay up late or complete tasks early the next morning.

## Arms Race Schedule\#

Arms Race is the daily solo competition that rewards consistent activity. The event runs continuously with **six 4-hour phases** cycling throughout each 24-hour period.

### Phase Rotation\#

The six Arms Race phases follow a fixed order that now aligns with Alliance VS days following a recent update:

| Phase | Name | How to Earn Points |
| --- | --- | --- |
| **Phase 1** | Hero Advancement | Upgrading hero levels and recruiting new heroes |
| **Phase 2** | City Building | Completing building upgrades and opening construction gift boxes |
| **Phase 3** | Unit Progression | Training troops and upgrading existing units to higher levels |
| **Phase 4** | Tech Research | Completing research projects in the Technology Center |
| **Phase 5** | Drone Boost | Using drone combat data and spending stamina |
| **Phase 6** | Shiny Tasks | Special daily objectives |

Each phase lasts exactly **4 hours** before transitioning to the next. The phase order is standardized across servers, and phase timing generally aligns with VS days following recent updates.

### Arms Race Timing Strategy\#

**Check the Schedule**: Click the calendar icon in the upper left corner of the Arms Race event page. This shows the full daily schedule with current and upcoming phases for your server.

**Double-Dip Points**: Since phases now align with VS days, your Monday Arms Race phases will match Monday VS activities, making it easier to earn points in both events simultaneously.

### Slot Swap Feature\#

The slot swap feature allows you to complete two phases during a single time period:

- If a phase falls during inconvenient hours like 3:00 AM, you can swap it earlier in the day
- Complete it alongside another phase and skip the late-night session entirely
- **Limitation**: You can only swap once per day and only with future phases that have not started yet

### Daily Badge Requirements\#

To unlock all three daily chests (Bronze, Silver, Gold), you need **18 Arms Race badges**:

| Chest | Badges Required | Total Badges Needed |
| --- | --- | --- |
| Bronze | 2 badges | 2 |
| Silver | 6 badges | 8 |
| Gold | 10 badges | 18 |

Each phase offers three chests worth 1, 2, and 3 badges respectively. **Completing three full phases per day guarantees all daily rewards.**

## Alliance VS Weekly Schedule\#

Alliance Duel VS is the 6-day competitive event where your alliance battles another alliance through themed daily challenges. The schedule runs **Monday through Saturday** with each day featuring different point-earning activities.

### Daily Themes\#

| Day | Theme | Point-Earning Activities |
| --- | --- | --- |
| **Monday** | Radar Training | Radar missions, gathering resources, spending stamina, drone activities |
| **Tuesday** | City Building | Building upgrades, construction speedups, survivor recruitment |
| **Wednesday** | Tech Research | Research completion, Valor Badge spending, drone component chests (L1-7) |
| **Thursday** | Hero Training | Hero level upgrades, skill medal usage, hero recruitment |
| **Friday** | Total Mobilization | Base, tech, and troop activities ( **4x training multiplier**) |
| **Saturday** | Enemy Buster | PvP - killing enemy troops ( **5x points** for VS opponent kills) |

### VS Day Strategy Tips\#

**Day 1 (Monday)**: Start gathering squads before reset so they return during the scoring period.

**Day 2 (Tuesday)**: Save building completions from the previous day and open them today.

**Day 3 (Wednesday)**: Open Drone Component chests Level 1-7 (Wednesday only counts).

**Day 4 (Thursday)**: Save Hero EXP, shards, and skill medals throughout the week for this day. This is typically the highest personal score day.

**Day 5 (Friday)**: Use training speedups - the **4x multiplier** makes this the best time.

**Day 6 (Saturday)**: If participating, attack opponent alliance bases for 5x points. If not participating, **shield up before reset Friday night** to avoid giving free points.

### VS Scoring Rules\#

- A **5-minute countdown** occurs after server reset before point scoring begins
- Any actions completed during this countdown period **will not count** toward VS points
- Wait for the countdown to finish before claiming resources, completing builds, or spending materials
- Points are tallied at the end of each 24-hour period
- The alliance with more points wins the day and earns victory points
- At the end of the 6-day cycle, the alliance with more daily wins takes the weekly reward

## Weekly Event Rotation\#

Hot Deal events follow a predictable weekly rotation that differs between active seasons and off-season periods. Understanding this rotation helps you plan purchases and resource allocation.

### Season Schedule (8 Weeks)\#

During an active season, Hot Deal events typically follow this rotation:

| Week | Events |
| --- | --- |
| **Week 1** | Exclusive Weapon Battle Pass #1 (typically Tank hero), Season Battle Pass begins |
| **Week 2** | Standard Hot Deals rotation |
| **Week 3** | Zombie Invasion (Golden Zombies), Glittering Market, Exclusive Weapon Battle Pass #2 (typically Aircraft hero) |
| **Week 4** | Standard Hot Deals, Warzone Declaration Event begins |
| **Week 5** | General's Trial |
| **Week 6** | Exclusive Weapon Battle Pass #3 (typically Missile hero) |
| **Week 7** | Zombie Invasion, Glittering Market |
| **Week 8** | Settlement period, rewards distributed |

**Note**: The season schedule resets completely when a new season begins, regardless of where you were in the off-season rotation.

### Off-Season Schedule (4+ Weeks)\#

During the off-season, events follow a simplified 4-week rotation that repeats until the next season starts:

| Week | Events |
| --- | --- |
| **Week 1** | General's Trial |
| **Week 2** | Standard rotation |
| **Week 3** | Zombie Invasion, Glittering Market |
| **Week 4** | Standard rotation |

Off-season has no fixed duration. It runs for a minimum of 4 weeks to complete one full cycle, then repeats until the next season launches.

## Biweekly Events\#

### Zombie Invasion (Golden Zombies)\#

**Frequency**: Every two weeks
**Duration**: Three days
**When**: Weeks 3 and 7 of each season, Week 3 of off-season rotation

Golden zombies spawn across the map offering massive resource rewards, especially gold:

- Small golden skulls appear randomly in clusters
- Defeating them gives a chance to spawn Boss Zombies with significantly higher rewards

### General's Trial\#

**Frequency**: Every 1-2 weeks
**Duration**: Three days
**When**: Weeks 1 and 5 of seasons, Week 1 of off-season rotation

A hybrid PvE event where you battle Vanguard Instructor bosses at increasing difficulty levels:

- Both individual and alliance participation matter
- Rewards include **Ability Medals** crucial for hero promotion

* * *

## Monthly Events\#

### Zombie Siege\#

**Frequency**: Approximately once per month
**Type**: Large-scale alliance defense event

Your alliance must survive **20 escalating waves** of zombie attacks targeting every member's base:

- Success requires coordination with stronger players reinforcing weaker members
- Tests collective alliance strength rather than individual power
- **Preparation**: Ensure all members have defense squads assigned and hospitals upgraded

### Glittering Market\#

**Frequency**: Monthly (typically Weeks 3 and 7 of seasons)
**Type**: Premium purchasing event

Glitter Coins unlock exclusive items:

- Free daily coins are available
- F2P players can accumulate currency between events
- Priority purchases: Mythic Blueprints, base skins

* * *

## Season-Specific Events\#

### Season War Days\#

During active seasons, additional events layer on top of the regular rotation:

**War Declaration Days**: After Week 4, Day 3, war can only be declared on **Thursday and Saturday**. Before this point, you can declare war daily. The limit is always 2 declarations per day.

**Alliance Safe Time (Season 5+)**: Three attack windows per war day:

- 04:00-05:00 server time
- 12:00-13:00 server time
- 20:00-21:00 server time

Available windows depend on current season rules. Alliances select one protected window per war day. Earlier seasons may have different mechanics.

**Cross-Warzone Expeditions**: Unlock Week 3, Day 2, allowing territory expansion on other servers.

### Battle Pass Windows\#

Exclusive Weapon Battle Passes appear at specific points during seasons:

| Timing | Hero Type | Example Heroes |
| --- | --- | --- |
| Week 1, Day 4 | Tank | Kimberly |
| Week 3, Day 4 | Aircraft | DVA |
| Week 6, Day 4 | Missile | Tesla |

Each Battle Pass runs for exactly **7 days**. Missing these windows means waiting for off-season Black Market or the next seasonal rotation.

## Daily Activity Checklist by Timezone\#

### For Eastern Time Players (Reset at 9 PM)\#

**Evening Session (9:00 PM - 11:00 PM)**

- Collect VIP daily chest immediately after reset
- Claim free Daily Sale and Weekly chests (10 diamonds each)
- Complete 3 likes in 3v3 Brawl Arena (30 diamonds)
- Check radar tasks and queue new ones
- Collect base resources and armed trucks
- Start long building and research queues for overnight

**Morning Session (Before Work)**

- Claim first free 50 stamina recharge
- Check Arms Race phase and complete if useful
- Attack zombies and complete radar missions with available stamina
- Set gathering squads if VS Day 1 is approaching

**Afternoon Session (4+ hours after morning)**

- Claim second free 50 stamina recharge
- Continue Arms Race participation
- Join alliance rallies for the daily count

### For UK/European Players (Reset at 2-3 AM)\#

**Morning Session (Wake Up)**

- Server has reset overnight
- Collect VIP chest and free shop chests
- Claim both 50 stamina recharges if 4+ hours have passed since the first would have been available
- Review Arms Race standings and catch up on missed phases

**Daytime Sessions**

- Continue normal gameplay with Arms Race phases
- Prepare materials for evening VS activities if applicable

**Evening Session**

- Final VS push before going to sleep
- Set up overnight activities like gathering and long construction

### For Asian/Australian Players (Reset at 10 AM - 12 PM)\#

**Midday Session (Around Reset)**

- Perfect timing for daily reset activities
- Collect all daily freebies immediately
- First stamina recharge available instantly

**Afternoon Session**

- Arms Race phases align well with afternoon hours
- Second stamina recharge available by late afternoon

**Evening Session**

- Complete daily checklist before bed
- Set overnight gathering and construction

## Stamina Management Schedule\#

Stamina regenerates passively at **1 point every 5 minutes** (12 per hour) when your bank is below 120. Managing stamina timing is critical for event efficiency.

### Free Stamina Sources Daily\#

| Source | Amount | Availability |
| --- | --- | --- |
| Recharge #1 | 50 stamina | At reset |
| Recharge #2 | 50 stamina | 4 hours after #1 |
| Passive regeneration | Up to 288/day | If stamina stays below cap most of the time |

### Weekly Stamina Opportunity\#

VIP Shop offers **250 stamina for 300 diamonds** once per week (40% discount compared to regular 100 stamina for 300).

### Stamina Saving Strategy\#

Save stamina items (not regeneration) for high-value events:

- Enemy Buster day
- Zombie Invasion
- Major rally events
- Using stamina tokens during **Drone Boost Arms Race phase** provides double value

## Planning Your Week\#

### Sunday\#

- Prepare for Monday VS Day 1 by queuing gathering squads to return after reset
- Check which Hot Deal events are active
- Review alliance assignments for the upcoming VS week

### Monday (VS Day 1 - Radar Training)\#

- Collect returning gatherers immediately after the 5-minute countdown
- Complete radar tasks throughout the day
- Focus Arms Race phases that align with radar and stamina activities

### Tuesday (VS Day 2 - City Building)\#

- Open building gift boxes saved from previous day
- Use construction speedups strategically
- Start long tech research to complete Wednesday

### Wednesday (VS Day 3 - Tech Research)\#

- Complete research projects
- Spend Valor Badges on Alliance Duel tech (counts for VS points AND improves future performance)
- Open Drone Component chests Level 1-7 (Wednesday only)

### Thursday (VS Day 4 - Hero Training)\#

- Use all saved Hero EXP, shards, and Skill Medals
- Recruit heroes if you have tickets
- This is typically the highest personal score day for active players

### Friday (VS Day 5 - Total Mobilization)\#

- Use training speedups (4x multiplier today)
- Complete building and research that contributes to power
- Prepare troops and shields for tomorrow

### Saturday (VS Day 6 - Enemy Buster)\#

**If participating:**

- Attack opponent alliance bases for 5x points
- Have shields ready for protection between attacks

**If not participating:**

- Shield up before reset Friday night to avoid giving free points

## Frequently Asked Questions\#

### What time does the server reset?\#

Server reset occurs at **00:00 server time (UTC-2)**, which equals **02:00 UTC**. For Eastern Time, this is 9:00 PM (winter) or 10:00 PM (summer). Check the timezone conversion table above for your local time.

### Why did my event schedule change when a new season started?\#

Season starts reset the entire event rotation to Week 1 regardless of where you were in the previous cycle. This can cause confusion if you expected the pattern to continue, but all servers follow the same reset when seasons begin.

### Can I earn VS points immediately after reset?\#

**No.** A 5-minute countdown occurs after server reset before VS scoring begins. Actions completed during this countdown do not earn points. Wait for the countdown to finish before claiming resources or completing tasks.

### How do I know what Arms Race phase is currently active?\#

Click the **calendar icon** in the upper left corner of the Arms Race event page. This shows the full daily schedule with current and upcoming phases for your server.

### When does Zombie Invasion appear?\#

Zombie Invasion (Golden Zombies) is a biweekly event that typically appears during **Weeks 3 and 7** of each season, and **Week 3** of the off-season rotation. The event runs for three days.

### How long do seasons last?\#

Seasons run for **8 weeks (48 days)**. Week 8 is the settlement period where territory captures freeze and rewards are distributed. Off-season runs for a minimum of 4 weeks before the next season begins.

### Does the Arms Race slot swap give extra rewards?\#

**No.** The slot swap feature provides timing flexibility but not additional rewards. You still earn the same 36 total points from 6 daily slots. Use it to optimize your schedule, not to gain extra advantages.

### When are War Declaration Days during seasons?\#

After Week 4, Day 3, war can only be declared on **Thursday and Saturday**. Before this point, you can declare war daily. The limit is always 2 declarations per day.

### What resets weekly versus daily?\#

| Daily Resets | Weekly Resets |
| --- | --- |
| Quest progress | Alliance VS cycle (starts fresh Monday) |
| VIP chest | VIP shop stamina discount |
| Free shop chests | Some Hot Deal rotations |
| Alliance help capacity |  |
| Arms Race opponents |  |
| VS day theme |  |

### How do I convert server time to my local time?\#

Server time is **UTC-2**. Add 2 hours to convert to UTC, then apply your local UTC offset. For example, if you are in UTC+0 (UK winter), add 2 hours to server time. If server shows 14:00, your local time is 16:00.
