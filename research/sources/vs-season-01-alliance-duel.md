The Alliance VS Duel is a six-day competition [L19].

### **Daily Scoring Activities**
*   **Day 1 (Radar Training):** Using stamina, completing radar tasks, using hero XP, using drone parts/battle data, opening drone chip chests (from day 85), and gathering resources [L39-62].
*   **Day 2 (Base Expansion):** Using building speedups, increasing building power, sending UR trucks, completing legendary secret tasks, recruiting survivors, and using armament materials (Season 4+) [L87-122].
*   **Day 3 (Age of Science):** Using tech research speedups, increasing tech power, using Valor Badges, completing radar tasks, and opening drone component chests [L131-164].
*   **Day 4 (Train Heroes):** Elite recruitment, using hero XP, using hero shards, and using skill medals [L173-192].
*   **Day 5 (Total Mobilization):** Completing radar tasks, building/tech speedups, and training units (the main source) [L206-220]. Late seasons include upgrading Gorilla Overlord and training T11 soldiers [L227-230].
*   **Day 6 (Enemy Buster):** Sending UR trucks, completing legendary secret tasks, using any type of speedup, and killing/losing units [L242-258].

### **Scoring Schedule**
The competition lasts six days [L19]. Winning a daily stage earns points for the alliance:
*   **Day 1:** 1 point [L19].
*   **Days 2–5:** 2 points each [L19].
*   **Day 6:** 4 points [L19].

### **Participation & Preparation Rules**
*   **Preparation:** Hoard resources for specific theme days throughout the week [L23, L30]. For Radar tasks, complete them beforehand but do not claim rewards until the specified day [L46, L163]. Send troops to gather resources on Sunday so they return after the server reset [L65].
*   **Synchronization:** Coordinate tasks with the "Arms Race" event [L23, L29].
*   **Discipline:** Spend resources only on their designated theme days [L30]. 
*   **Coordination:** Follow alliance leadership's instructions regarding whether to go all-in or save resources [L31].
*   **Security:** Always activate a shield on Friday evening [L32, L267].
*   **Technical:** Avoid performing actions during the 5–7 minute server reset window [L33].

### **Victory Conditions**
*   **Overall Duel Victory:** You need to score 7 points [L21]. A recommended strategy is winning every day from Monday to Thursday [L21].
*   **Individual Progress:** A progress bar fills daily, and players can claim up to three levels of reward chests (Basic, Advanced, and Super) based on point thresholds (540,000; 2,300,000; and 7,200,000) [L302-306]. It is suggested to score 7.2 million points daily to claim all personal rewards [L312].
