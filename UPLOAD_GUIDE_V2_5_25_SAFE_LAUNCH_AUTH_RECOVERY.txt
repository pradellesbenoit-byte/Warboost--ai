APRÈS L'UPLOAD
--------------
1. Attendre que Vercel termine le Preview de public-beta-safe-launch.
2. Dans Supabase > Authentication > URL Configuration, garder Site URL = https://warboost.fr pour le moment.
3. Ajouter dans Redirect URLs :
   https://warboostv4-git-public-beta-safe-launch-warboost.vercel.app/reset-password.html
4. Tester depuis la Preview : Compte > Mot de passe oublié ?
5. Vérifier que le mail ouvre la page V2.5.25 « Choisir un nouveau mot de passe ».
6. Définir un nouveau mot de passe, puis se reconnecter.
7. Vérifier qu'aucune donnée joueur existante n'a disparu.
