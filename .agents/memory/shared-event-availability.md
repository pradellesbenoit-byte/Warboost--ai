---
name: Shared event availability
description: Rules for availability evidence and event-specific alliance planning.
---

Availability for alliance events must remain explicit, event-scoped, sourced, and reliability-aware. Missing data is “to confirm,” never absence. Canyon state stays separate from Desert Storm while using the generic event availability engine intended for Desert, Canyon, VS, and Season.

**Why:** An empty or incomplete cloud copy must not erase a positive local confirmation, and planning must never infer inactivity, absence, or weakness from missing observations.

**How to apply:** Merge availability by canonical member, event, and time slot. Protect a sourced known status from an unsourced unknown row. Use only explicit presence for starters/substitutes and retain unknown or uncertain players in a confirmation queue.
