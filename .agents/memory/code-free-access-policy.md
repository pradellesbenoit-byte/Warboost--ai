Alliance membership is scoped by server and tag, with verified identity/manager approval. A self-declared rank or self-authored roster is not independent proof for bootstrapping ownership. Payments remain OFF/TEST; the planned monthly price is not a sale authorization.

Without independent Last War role proof, allow an empty independent provisional workspace with a WarBoost founder, not a verified in-game R4/R5. Private draft preparation must not access, reserve, absorb or replace an existing alliance, grant membership or link accounts.

**Why:** The owner explicitly approved this restricted alternative to blocking every first founder.

**How to apply:** Keep provisional founder data outside canonical alliance authority. Clearly label declared game ranks as unverified and require separately reviewed evidence before granting canonical management rights.
