---
name: WarBoost commercialisation — limites utilisateur
description: Gratuité des bêta-testeurs, indépendance des droits PRO/alliance et autorisation distincte pour LIVE.
---

Les bêta-testeurs actuels doivent conserver PRO gratuitement pendant la phase bêta. Un nouvel abonné payant ne doit pas dépendre d’un ancien code bêta pour accéder aux fonctions PRO.

**Why:** L’utilisateur exige cette séparation pour préparer la commercialisation sans retirer les droits des testeurs.

**How to apply:** Préserver le droit gratuit existant séparément de l’abonnement. Ne pas convertir une invitation d’alliance en abonnement et ne pas attribuer R4/R5 à partir d’un paiement.

La phase de préparation Stripe demandée est TEST uniquement : aucun paiement réel, aucune clé live, aucun basculement live. Les migrations doivent être versionnées sans application automatique en production.

**Why:** L’utilisateur a explicitement limité cette phase à TEST et interdit le push et le déploiement automatiques.

**How to apply:** Une réussite avec fournisseurs simulés ne prouve ni un paiement Stripe test réel ni une autorisation LIVE. Signaler séparément les résultats simulés, les essais Stripe encore nécessaires et la préparation LIVE.
