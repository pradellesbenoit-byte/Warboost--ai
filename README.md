# WarBoost V2.5.2 — Primary Squad Reliability

WarBoost V2.5.2 conserve la permutation complète de V2.5.1 et corrige la notion d’escouade principale : **Escouade 1 est désormais la priorité choisie par le joueur dès qu’elle contient des données**, même si une escouade secondaire possède davantage de puissance.

Après une permutation, le Coach IA, le Diagnostic PRO, le contexte méta et la Boutique IA suivent donc la nouvelle Escouade 1. Une escouade secondaire plus puissante reste visible comme information séparée, mais elle ne remplace plus silencieusement l’escouade principale.

## Garanties conservées
- permutation atomique de deux escouades complètes ;
- EX, niveaux, étoiles, puissance, équipement et Éveil restent attachés à l’identité du héros ;
- mémoire héros V2.5.0/V2.5.1 conservée ;
- aucun transfert par position ;
- Saison 6 Awakening/Reshape conservée ;
- Boutique IA alignée sur l’Escouade 1 choisie ;
- contexte VS/PvP/PvE/Saison conservé ;
- aucune quantité de fragments inconnue n’est inventée ;
- indication séparée lorsqu’une escouade secondaire est plus puissante ;
- libellés V2.5.2 disponibles dans les 23 choix de langue explicites + Auto.

L’intégration officielle Last War reste en attente d’autorisation ; WarBoost continue de fonctionner avec les scans, les données consenties et le cloud WarBoost autorisé.
